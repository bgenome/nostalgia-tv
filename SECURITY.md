# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within Nostalgia TV, please send an email to guybelo@me.com rather than opening a public issue.

Please provide:
- A description of the issue and potential impact
- Detailed reproduction steps or proof-of-concept
- Any suggestions for mitigation

We will acknowledge receipt within 48 hours and coordinate a fix and release.
